The scanner is in `src/renderer/board/scanner.ts`. It is a pure state machine: the app owns the clock and calls `tick()` and `select()`.

## States

```text
rows ──select──▶ cols ──select──▶ key returned, back to rows at the top
  ▲               │
  └── ↩, or two unselected passes ──┘
```

## Late reactions

People react after they see a change. If a select arrives within 350 ms of the highlight moving, the user was almost certainly reacting to the previous item, so the scanner picks that one. This matters more for a gesture than for a key press, because the gesture itself takes time to detect.

## The timer

The app schedules each step with a timer, restarted on every select, so you always get a full step after a gesture. It does not advance while the SDK's validation is failing.
