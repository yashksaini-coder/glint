# Glint docs

The documentation site for [Glint](../README.md), built with [Fumadocs](https://fumadocs.dev) on Next.js.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

Pages are MDX files in `content/docs`. Every page is also served as Markdown (`/docs/scope.md`), and the whole site as `/llms.txt` and `/llms-full.txt`.
